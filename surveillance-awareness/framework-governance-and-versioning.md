# Framework Governance & Versioning

This document defines how the Surveillance Awareness framework of the Community Cyber Defense Project is maintained, versioned, reviewed, corrected, updated, and eventually deprecated.

The goal is to ensure that organizations, researchers, residents, journalists, students, public officials, and other users can determine:

- Which version they are using
- When a resource was last reviewed
- Whether information is current
- What changed between versions
- Whether older reports remain compatible
- How corrections are handled
- When research should be reverified
- When a resource has been replaced

---

# Why Framework Governance Matters

Surveillance technology changes.

Vendor products change.

Government policies change.

Contracts expire.

Security practices evolve.

Laws change.

Research improves.

A framework intended for long-term community use cannot remain static.

It needs a transparent maintenance process.

---

# Governance Principle

**Every published resource should make its currency, version, and limitations understandable.**

Users should not have to guess whether they are reading:

- Current guidance
- Historical guidance
- A draft
- A superseded resource
- An archived resource
